A Python program (standard library only) that draws a 1024x1024 product-catalogue photo, as a PNG, of an impossible gadget: the RAINBREW 3000, an espresso machine that brews rain. Running it writes the catalogue image to /output/entry.png, deterministically — every run produces byte-identical output.

## Run it

```sh
python3 main.py
```
